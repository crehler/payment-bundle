## Czym jest Shopware?

[Shopware 6](https://www.shopware.com/) to nowoczesna platforma e-commerce open source, na której działają tysiące sklepów internetowych w Europie. Daje pełną kontrolę nad wyglądem sklepu, procesem zakupowym i integracjami, a jej modułowa architektura pozwala rozszerzać sklep o wtyczki — takie jak wtyczki płatności z tego ekosystemu.

Shopware działa też w modelu **headless** — całą logikę sklepu udostępnia przez **Store API**, dzięki czemu warstwę zakupową można zbudować na dowolnym froncie (np. aplikacja Nuxt/PWA, aplikacja mobilna), niezależnie od wbudowanego Storefrontu. **Wtyczki oparte o ten bundle obsługują oba światy** — działają zarówno w klasycznym Storefroncie, jak i w pełni przez Store API (w tym dedykowany endpoint dla BLIK Level 0), więc sprawdzą się także w sklepach headless.
